# 命书字体清单

本目录只放允许嵌入、印刷与商业项目使用的开源字体。命书正文不依赖用户电脑上
预装的字体，导出 PDF 时会把字体子集嵌入文件。

| 文件 | 页面角色 | 上游项目 | 许可证 |
| --- | --- | --- | --- |
| `NotoSerifSC-Regular.ttf` | 正文、章标题、数字 | Google Fonts / Noto Serif SC（与 Source Han Serif 同源） | SIL OFL 1.1 |
| `NotoSansSC-Regular.ttf` | 图表标注、小字、网页控件 | Google Fonts / Noto Sans SC | SIL OFL 1.1 |

书法标题与竖排寄语使用 **马善政毛笔楷书（Ma Shan Zheng）**。其 Google Fonts
发行版同样使用 SIL OFL 1.1；`MaShanZheng-Regular.ttf` 已从 Google Fonts 官方
静态资源地址取得，仅用于封面、寄语和章节大字，正文仍使用思源宋体。

官方来源：

- https://github.com/google/fonts/tree/main/ofl/notoserifsc
- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/mashanzheng
- https://github.com/adobe-fonts/source-han-serif

OFL 允许个人与商业使用、印刷、嵌入、修改与再分发；不得把字体文件本身单独出售，
再分发时应保留许可证与版权声明。详见同目录 `SIL-OFL-1.1.txt`。
