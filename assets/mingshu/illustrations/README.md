# 命书开篇插画资产

本目录中的图片不包含排盘文字。页面在运行时将真实排盘、标题、说明与插画分层装配，避免生成式图片中的伪文字，也便于同一素材复用到不同命例。

- `covers/`：A5 竖版封面底图，中央保留标题与姓名安全区。
- `layout/`：开篇固定页底图，包括阅读说明、首页寄语、五行罗盘；均为无文字 RGB PNG。
- `daymasters/`：20 张透明 PNG，十天干 × 男/女；文件名为 `{天干}-{male|female}-v1.png`。
- `seasons/`：12 张月令季节图，按十二地支分别取象。
- `zodiac/`：12 张透明 PNG，统一为亲和、喜庆、不过度幼态的当代年画风。
- `sources/`：保留生图母版及抠图前的纯色背景图，便于未来重做透明边缘。

透明资产先以纯色 chroma 背景生成，再用项目内标准去色流程生成柔和透明边缘并消除溢色。最终印刷 PDF 会整体栅格化为不透明 DeviceRGB 页面，以规避部分 PDF 阅读器对透明遮罩、混合模式和 CSS mask 的错误渲染。

视觉关键词：宣纸、宋刻骨架、朱砂、黛青、矿物青绿、旧金、留白、年画纹样。
